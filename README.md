# 병동 현황판

간호 스테이션 의료진을 위한 병동 환자 현황 관리 대시보드입니다. UX/UI 과제용 프로토타입이에요.

**바로 보기:** https://jelincc.github.io/ward-dashboard/

## 화면 구성
- **대시보드**: 지금 배정 가능한 병상(남·여 구분), 병실 배치도, 진료과별 입원 현황, 주간·월간 입퇴원·수술·중환자실 이동, 빈 병상 전년 대비 비교와 7일 예측
- **환자 현황**: 신속 확인 환자(즉시·주의, 확인 이유와 확인 기록), 병실별 환자 목록(필터, 정렬, 검색)
- **오늘 입·퇴원**: 퇴원 4단계, 입원 3단계 체크와 퇴원 처리, 입원 완료 처리
- **병상 배치·배정**: 병상 대기 환자 배정(성별 병실, 격리 조건 확인), 정리 중 병상 완료 처리
- **환자 상세**: 두 가지 식별자, 바이탈 추이, 간호 기록
- **설계 노트**: 문제 정의, 가설, 레퍼런스, 의사결정과 트레이드오프

## 참고
- 모든 환자, 병원명, 수치는 예시 데이터입니다.
- 처리한 체크, 배정, 퇴원 기록은 브라우저에만 저장됩니다. 왼쪽 아래 "예시 데이터 처음 상태로 되돌리기"로 초기화할 수 있어요.
- 단일 `index.html` 파일이며 빌드 과정이 없습니다.
